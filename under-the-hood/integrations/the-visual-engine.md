# The Visual Engine

> The Visual Engine is a set of next-level shaders and powerful tools designed to unify any asset from the Unity Asset Store, Megascans, Speedtree, Tree Creator, and more, or custom models made by your team.

<p align="center"><a href="https://assetstore.unity.com/packages/vfx/shaders/the-visual-engine-286827?aid=1011luj9X" class="button secondary">Purchase</a></p>

{% hint style="warning" %}
Important! Crest 5 is only supported with Planar reflections enabled. See [#reflections](the-visual-engine.md#reflections "mention") for more information
{% endhint %}

## Installation

No installation required.

## Scene Setup

Integration requires no scene setup.
