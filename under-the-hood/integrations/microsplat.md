# MicroSplat

> MicroSplat is a modular shader generation system for Unity Terrains and meshes.

<p align="center"><a href="https://assetstore.unity.com/packages/tools/terrain/microsplat-96478?aid=1011luj9X" class="button secondary">Download</a></p>

## Installation

Requires no further installation once Microsplat and COZY 4 are both installed.

## Scene Setup

Requires an [iclimatemodule.md](../../using-cozy/modules/climate-module/iclimatemodule.md "mention") for wetness and snow.

Requires an [iatmospheremodule.md](../../using-cozy/modules/atmosphere-module-1/iatmospheremodule.md "mention") for wind.

## Limitations

### URP

Unviersal Render Pipeline support for MicroSplat is a paid feature.

### Extensions

This integration interfaces with some of the custom modules built for Microsplat. This integration does _not_ add snow/rain accumulation unless the respective modules are used.
