# Upgrade Guide

Thank you for considering the upgrade path for COZY 4. This guide outlines pricing, module changes, and what you need to know to transition smoothly to the new version.

#### Key Takeaways

* Modular System: COZY 4 continues the flexible, module-based architecture of previous versions. No modules are required unless you want their specific functionality.
* Pricing & Base Cost: The base price for COZY 4 is $80, covering all features advertised at launch.
* Discontinued Modules: _Habits_ and _Plume_ have been retired; their core functionality is now built directly into the native COZY 4 package.

#### Upgrade Pricing Matrix

| **User Status**   | **Upgrade Cost**        | **What's Included**                                                                                                              |
| ----------------- | ----------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| New Users         | $80                     | Full COZY 4 base package with launch features                                                                                    |
| COZY 3 Owners     | $30                     | Upgrade from COZY 3 to COZY 4                                                                                                    |
| Recent Buyers     | Free                    | For anyone who purchased COZY 3 within 30 days of the COZY 4 release                                                             |
| COZY 3 Pro Owners | $30 base + Free modules | $30 upgrade for COZY 4 base, plus free upgrades for all included modules (_Note: COZY 4 Pro bundles are not currently planned_). |

#### Optional Launch Modules ($15 each or $10 each)

Five upgraded modules from the COZY 3 catalogue will be available at launch, fully optimized to interface with the new COZY 4 system.

* Compatibility Note: These will be released as separate products so that users on BiRP or HDRP in Unity 6 can continue using legacy versions. If you already own the COZY 3 versions, you qualify for a free upgrade path to the COZY 4 counterparts.
