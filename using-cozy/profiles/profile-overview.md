# Profile Overview

Profiles in COZY are scriptable data assets that define reusable scenarios and state transitions for the weather and ambience systems. They are not usually mutated at runtime; instead, the runtime modules read them to decide how a scene should behave.

The main profile types are:

- [Weather Profile](weather-profile.md)
- [Atmosphere Profile](atmosphere-profile.md)
- [Climate Profile](climate-profile.md)
- [Ambience Profile](ambience-profile.md)
- [Forecast Profile](forecast-profile.md)
- [FX Profiles](fx-profiles/README.md)

This section focuses on concrete profile assets and leaves interfaces and infrastructure types out of the user-facing docs.
