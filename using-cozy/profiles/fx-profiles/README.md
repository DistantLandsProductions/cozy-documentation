# FX Profiles

FX Profiles are containers of data that are attached to [weather-profile.md](../weather-profile.md "mention") and [ambience-profile.md](../ambience-profile.md "mention")s that modify the world state when played. This adds a layer of abstraction from the metadata of the profile and the FX it plays. For example, if you wanted to make your dense fog even denser across the board, you change one value in one place not many values across different profiles.
