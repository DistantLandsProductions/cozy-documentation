# Code Generation

## What is VariableStack

VariableStack is a proprietary code generation plugin developed as a part of COZY 4. It functions by taking a list of variables and generating C# and HLSL files based on the data.&#x20;

## Setting Up VariableStack

In order to use VariableStack, you need to first add the COZY\_DEV scripting define symbol to your player settings:

<figure><img src="../.gitbook/assets/image (59).png" alt="" width="563"><figcaption></figcaption></figure>

After the scripts compile, you will see a new "Generate Variants" menu item under Tools/COZY: Weather 4
