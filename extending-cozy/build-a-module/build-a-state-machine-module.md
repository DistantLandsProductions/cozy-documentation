# Build a State Machine Module

State Machine modules are modules that handle scheduling, playing, and transitioning between profiles (such as the [weather-module](../../using-cozy/modules/weather-module/ "mention") or [ambience-module](../../using-cozy/modules/ambience-module/ "mention")). Profiles handled by a State Machine module _must_ implement IStateMachineProfile. See [cozystatemachinemodule-less-than-t-greater-than.md](../../using-cozy/modules/extra-interfaces/cozystatemachinemodule-less-than-t-greater-than.md "mention") for a tutorial on creating your own module.
